# 贪吃蛇 · Snake

一个无依赖的浏览器贪吃蛇小游戏。直接打开 `index.html` 即可游玩，也可以启动本地服务器：

```sh
python3 -m http.server 8000
```

然后在浏览器访问 `http://localhost:8000`。

- 方向键或 WASD 控制方向，手机可使用屏幕方向按钮。
- 空格开始或暂停，Enter 开始或重新开始。
- 吃到食物得 10 分，速度逐渐增加；撞墙或撞到身体会结束。
- 支持三档速度，最高分保存在当前浏览器中。
- 切换标签页时自动暂停。

运行逻辑测试（需要 Node.js 18 或更新版本）：

```sh
node --test tests/game.test.js
```
